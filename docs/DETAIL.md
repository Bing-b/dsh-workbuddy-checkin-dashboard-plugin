# 每日签到仪表盘

把已安装的 `dsh-connect-workbuddy-models`（负责真正签到的插件）每天的结果，变成一页能看的数据面板。

## 功能

- **左侧导航入口**：侧边栏出现「每日签到」一行，点一下就在主区域打开面板，和对话平级切换。
- **平台卡片**：每个账号一张卡，显示当前积分、今日领取状态、每档奖励，以及「立即领取」按钮，可直接触发签到。
- **今日汇总**：今日获得积分、总积分余额、下次自动签到时间。
- **签到流水**：按「账号 + 日期」记录每一次签到结果，可回看历史；数据来自本插件自己的落盘账本，不依赖上游保留历史。

## 数据来源

本插件不改动上游插件的代码与文件，只做两件事：

1. 定期调用它公开的接口 `GET /plugins/dsh-connect-workbuddy-models/status`；
2. 把结果折算成幂等流水，写入 `$DSH_HOME/dsh-checkin-dashboard/ledger.json`。

因此上游升级不会打坏这里；上游不可达时页面仍能打开，并在顶部说明原因。

## 使用

1. 左侧导航点「每日签到」；
2. 首次打开若列表为空，点右上角刷新；
3. 需要立刻签到就点卡片上的按钮，或依赖上游的自动签到（默认北京时间 9 点）。

## 限制

- **历史流水从安装本插件那天开始积累**：上游插件本身不保存每日历史，只能靠本插件轮询累积，装之前的日期无法补回。
- **不提供用量统计与成本估算**：上游没有公开相关接口，本插件不伪造数字。
- **只统计 WorkBuddy**：其它平台（Trae、Qoder）需要各自的签到插件提供接口后才能接入。
- **凭据不落地**：本插件只读上游公开的 HTTP 接口，不接触登录凭据；账本里只有账号名、余额与签到结果。
